# 12. 将报告必带项校验下沉到文件层由测试强制

- 状态：已接受
- 日期：2026-08-22

## 上下文

总结报告是对话输出不落盘，guard 和测试只能校验文件，无法直接检查对话内容。文字沉淀防不住漏，机制才能防漏，需把「漏」从对话层下沉到文件层。

## 决策

### 本质
对话输出不落盘、guard 校验不到；需把「漏」从对话层下沉到文件层。

### 最佳实践
机制防漏（文件层测试强制），不靠文字纪律提醒。

### 方案
利用落账会写进 verification.md 的事实，在 docs-consistency.test.mjs 增加强制校验：每个新任务段落的落账必须含全部必带项标题，否则测试红，机器兜住对话层防不住的部分。

## 后果

正面：对话中可能漏，但落账时测试会红强制补上；机制可重复执行，不依赖记忆。负面：需维护标记生效范围，历史段落不能误伤；测试逻辑增加复杂度。

## 被拒备选

仅靠写反例进 verification.md 作为纪律提醒：被拒，因为文字对对话输出无强制力，下次大概率还漏别的东西。
