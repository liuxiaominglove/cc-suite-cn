# 17. 强制模型 diff 审查并允许真机验证挂起但必须显式声明

- 状态：已接受
- 日期：2026-08-22

## 上下文

复审分两道：模型 diff 审查（AI 可独立完成）和真机验证（常需用户授权/在场）。缺少纪律导致跳过模型审查或用已修复掩盖未复审。

## 决策

### 本质
复审分「可自主（模型审查）」和「需用户（真机）」两道，缺纪律导致跳过或冒充完成；这是「流程/纪律」决策。

### 最佳实践
能自主完成的强制（跳过即违规）、需用户在场的允许挂起但必须显式声明。

### 方案
模型 diff 审查强制，AI 自己就能做，跳过即违规；真机验证允许因用户不在而挂起，但必须显式标注尚未复审及卡点和待办，禁止用编译/测试通过冒充复审完成。

## 后果

正面：杜绝跳过可自主完成的复审，明确挂起状态，提升可信度。负面：汇报需额外声明状态，可能增加沟通成本。

## 被拒备选

两道复审都强制：被拒，因真机验证常需用户在场，无法强制即时完成。两道都允许挂起：被拒，因模型审查无借口跳过。
