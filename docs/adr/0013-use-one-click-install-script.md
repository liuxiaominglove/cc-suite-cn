# 13. 用一键安装脚本简化下载安装流程

- 状态：已接受
- 日期：2026-08-22

## 上下文

当前安装流程为5大手动步骤，约75行说明，认知负担高，key需手抄进rc文件，clone慢，命令项目级。用户希望简化下载安装流程。

## 决策

### 本质
手动安装 5 步、认知负担高；简化流程，但 curl|bash 引入供应链风险（有损性）。

### 最佳实践
简化安装（一条命令），但 curl|bash 属供应链反模式，须配套安全网。

### 方案
在仓库根目录新增install.sh，配合GitHub raw分发，将安装收敛为一条curl|bash命令。脚本自动检测前置、装opencode和3个worker CLI、交互式询问3个API key并写入rc文件、clone到默认目录、装依赖、跑preflight。README安装章节缩为3行。

## 后果

正面：安装步骤大幅简化，降低认知负担，key输入更安全（read -s），幂等可重跑。负面：引入curl|bash供应链风险，key明文落盘自动化，自动装第三方代码，install.sh不在现有守卫和测试网内，需补强。

## 被拒备选

去掉必须cd进仓库的全局命令方案：与guard.mjs单一数据源规则冲突，属架构级改动，本次不做。GitHub Release+tarball替代clone：可提速但改动更大，本次不做。
