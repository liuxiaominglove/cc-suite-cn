# 16. 为 review-runner 增加 --diff-base 开关以支持已提交 diff 审查

- 状态：已接受
- 日期：2026-08-22

## 上下文

现有 /verify 只审查未提交的改动，对已提交并 push 的修复（如 macELTA 的 70b0301）无法直接复审，需手动抽取 diff。

## 决策

### 本质
/verify 只审未提交 diff，已提交（已 push）修复无法直接复审；可逆、无损。

### 最佳实践
工具化（加可复用开关），而非临时手动抽取 diff。

### 方案
在 review-runner.mjs 和 jobs.mjs 中增加 --diff-base <commit> 参数，使其能审查指定提交与当前 HEAD 之间的差异，支持对已提交修复的独立复审。

## 后果

正面：一劳永逸解决已提交 diff 的复审问题，可复用。负面：需额外开发与测试，增加工具复杂度。

## 被拒备选

手动抽取 diff 临时文件喂入：被拒，因不够干净可复用，仅作临时止血方案。
