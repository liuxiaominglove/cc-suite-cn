# 10. 用 --check-stale 子命令防止重复审查同一 diff

- 状态：已接受
- 日期：2026-08-22

## 上下文

同一 diff 可能被重复审查，浪费资源且结论可能过时。需要机制判断 diff 是否已审查过。

## 决策

### 本质
同一 diff 可能被重复审查、结论过时；可逆、无损。

### 最佳实践
机器判断（hash 比对）diff 是否已审，而非人工判断。

### 方案
在 review-gate 中新增 --check-stale 子命令：读取标记，若无标记或 diff 代码文件 hash 变化则允许审查，否则拒绝并提示上次结论仍有效。

## 后果

正面：避免重复审查，节省资源；确保结论基于最新代码。负面：hash 计算可能误判（如注释变化）；需维护标记文件。

## 被拒备选

仅靠人工判断：不可靠且易遗漏；每次强制审查：浪费资源且无意义。
