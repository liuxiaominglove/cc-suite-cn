# 11. 用单一数据源清单强制校验报告必带项

- 状态：已接受
- 日期：2026-08-22

## 上下文

总结报告漏带「总体结论」和「行动项」两节，原因是模板升级后执行未对照，行为模式依赖记忆缓存而非现场读模板。文字沉淀对对话输出无强制力，无法防止再次遗漏。

## 决策

### 本质
文字沉淀对对话输出无强制力（依赖记忆缓存）；这是「机制 vs 记忆」决策。

### 最佳实践
机器强制兜底——单一数据源清单 + 测试校验，不依赖记忆。

### 方案
在 scripts/report-sections.mjs 定义 5 个无条件必带项清单，docs-consistency.test.mjs 用同一份清单同时校验 SKILL.md 模板、AGENTS.md 汇报惯例、verification.md 标记后的落账段落，缺一项测试即红。

## 后果

正面：机器强制兜底，落账缺项会被测试拦截并精确报告；模板与指令漂移也能被同一清单发现。负面：需维护单一数据源，新增必带项要同步改清单；历史段落需标记区分，避免误伤。

## 被拒备选

仅加一条校验「总体结论」和「行动项」两个标题：被拒，因为只限制两个目标不够，无法覆盖其他可能遗漏的必带项，需定整体规则。
