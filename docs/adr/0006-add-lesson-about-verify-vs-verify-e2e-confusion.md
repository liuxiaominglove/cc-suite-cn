# 6. 在 SKILL.md 和 AGENTS.md 添加 verify 混淆教训反例

- 状态：已接受
- 日期：2026-08-22

## 上下文

本次错误根因之一是术语歧义，需在评审流程和指令中双重提醒，防止 opencode 走流程时再次混淆。

## 决策

### 本质
术语歧义需在「流程入口 + 指令」双重提醒防再犯；可逆、无损。

### 最佳实践
教训要落在「流程入口」（SKILL.md）+「指令」（AGENTS.md）双重覆盖，而非单点。

### 方案
在 SKILL.md Critical Rules 和 AGENTS.md 铁律各加一条：修 bug 后必跑 /verify（唯一复审），pnpm verify:e2e 是 release 门禁，两者别混。

## 后果

正面：双重提醒，降低再犯概率；负面：文档增加冗余，但成本极低。

## 被拒备选

不加提醒：仅靠对照表，可能被忽略。
