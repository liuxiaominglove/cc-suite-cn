# 5. 新增复审与门禁对照表并收窄未复审状态枚举

- 状态：已接受
- 日期：2026-08-22

## 上下文

AGENTS.md 中 /verify、pnpm verify、pnpm test:unit 的规则分散在七处，从未并排对照，导致规则串读；⏸️ 未复审状态允许模糊借口。

## 决策

### 本质
规则散落 + 模糊措辞给「门禁借口」留空间；可逆（改文档）、无损。

### 最佳实践
散落规则收敛成对照表；模糊状态收窄成可枚举的客观理由（防借口）。

### 方案
在 AGENTS.md Verification Discipline 段新增三命令对照表，并将 ⏸️ 状态收窄为三种客观理由（git diff 空、真机需授权、评审员空输出重试耗尽），明令门禁借口不合法。

## 后果

正面：规则一目了然，模糊借口被锁死；负面：文档变长，需维护一致性。

## 被拒备选

仅靠口头提醒：无约束力，无法防止再犯。
